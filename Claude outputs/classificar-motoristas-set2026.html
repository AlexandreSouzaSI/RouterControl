Pagamentos de motoristas por dia · Setembro/2026

Cada linha é um motorista num dia (com os CT-es daquele dia). Clique em mais de uma placa para dividir igual, ou em Dividir para informar o valor de cada uma. Marque a caixinha de várias linhas para classificar todas de uma vez. Atalhos: 1–8 placa · Shift+número soma outra placa · D dividir · S sugestão · Espaço marcar · 0 limpar · ↑↓ navegar. O que você classifica só sai de "Pendentes" quando clicar em Salvar progresso.
